# Contributing

1. Create a feature branch off `main` (e.g. `feature/add-tags-support`).
2. Implement your changes. Do not touch existing SkillLinkr core files.
3. Run `npm run lint` and `npx tsc --noEmit` and ensure zero errors.
4. Run `npm run test` (Vitest) and `npx playwright test` to verify no regressions.
5. Submit a PR.
